Status sumber

Bar status di bagian bawah peta menunjukkan hasil terakhir yang diamati aplikasi dari setiap sumber: Aktif, Gangguan, Simulasi, atau Belum dicek. Sentinel-2 hanya dicek saat citra diminta untuk sebuah insiden. Arahkan kursor ke sebuah sumber untuk melihat waktu pemeriksaan terakhir dan alasan gangguannya.

Catatan

  • Hasil OpenStreetMap disimpan 7 hari agar tidak membebani server Overpass publik.
  • Bila semua server Overpass gagal, data OSM diambil dari salinan offline ekstrak Geofabrik (bertanggal), dan bar status menampilkan OSM sebagai Salinan offline.
  • Citra NASA GIBS hanya untuk tampilan. Citra itu tidak dipakai sebagai bukti, dan awan bisa menutupi asap.

Source status

The status bar at the bottom of the map shows what the app last observed from each source: On, Down, Simulation, or Not checked. Sentinel-2 is checked only when images are requested for an incident. Hover a source to see when it was last checked and why it is down.

Notes

  • OpenStreetMap results are cached for 7 days to spare the public Overpass servers.
  • When every Overpass server fails, OSM data comes from a dated offline copy of the Geofabrik extract, and the status bar shows OSM as Offline copy.
  • NASA GIBS imagery is for display only. It is not used as evidence, and clouds can hide smoke.
