Kebijakan privasi

Diperbarui 28 Oktober 2026.

Halaman peta bisa dipakai tanpa akun. Data pribadi hanya masuk bila Anda mengirim laporan lewat halaman Lapor.

Yang dikumpulkan saat Anda melapor

  • Lokasi dari GPS ponsel atau titik yang Anda pilih di peta.
  • Foto (1 sampai 3). Setiap foto diubah ulang menjadi JPEG tanpa metadata, sehingga data EXIF seperti GPS dan merek ponsel dihapus sebelum disimpan.
  • Pesan suara (opsional), disimpan seperti saat direkam dan diubah menjadi teks.
  • Keterangan teks (opsional).

Kami tidak meminta nama, akun, nomor telepon, atau email.

Yang tidak disimpan

Alamat IP tidak disimpan oleh aplikasi. Untuk membatasi spam (6 laporan per jam), alamat Anda diubah menjadi kode acak satu arah (hash) yang hanya ada di memori server dan hilang saat server dimulai ulang.

Siapa yang bisa melihat

  • Foto, pesan suara, teks, dan lokasi persis hanya terlihat oleh verifikator.
  • Peta publik membulatkan lokasi ke sekitar 100 m.
  • Insiden yang hanya berasal dari laporan warga baru tampil di peta publik setelah disetujui verifikator. Foto dan suara warga tidak pernah ditampilkan ke publik.

Pemrosesan oleh pihak lain

  • Foto dan pesan suara dikirim ke Meta Model API untuk dibaca dan ditranskripsi (Muse Spark, SAM, Muse Voice Transcribe).
  • Baseten hanya menerima klaim yang berasal dari data publik, tidak pernah data laporan warga.
  • Saat membuka peta, browser Anda memuat tile peta dari OpenFreeMap, citra dari NASA GIBS, dan pustaka MapLibre dari unpkg. Layanan itu melihat alamat IP Anda seperti situs web lain.

Penyimpanan di browser

Tidak ada cookie, iklan, atau analitik. Browser hanya menyimpan pilihan bahasa, status panel samping, dan token verifikator (khusus verifikator) di localStorage.

Lama penyimpanan dan penghapusan

Laporan disimpan selama masa demo hackathon, lalu dihapus. Verifikator dapat menghapus seluruh data warga dari satu insiden kapan saja. Untuk meminta penghapusan, buka GitHub Issues dan sebutkan nomor insiden saja, tanpa data pribadi.

Privacy policy

Updated 28 October 2026.

The map can be used without an account. Personal data enters only when you send a report through the Report page.

What a report collects

  • Location from your phone's GPS or the point you pick on the map.
  • Photos (1 to 3). Every photo is re-encoded as JPEG without metadata, so EXIF data such as GPS and phone model is removed before storage.
  • Voice note (optional), stored as recorded and transcribed to text.
  • Text description (optional).

We do not ask for a name, account, phone number, or email.

What is not stored

The app does not store IP addresses. To limit spam (6 reports per hour), your address is turned into a one-way code (hash) that lives only in server memory and is gone when the server restarts.

Who can see it

  • Photos, voice notes, text, and the exact location are visible to verifiers only.
  • The public map rounds locations to about 100 m.
  • An incident built only from citizen reports appears on the public map only after a verifier approves it. Citizen photos and voice are never shown publicly.

Processing by others

  • Photos and voice notes are sent to the Meta Model API to be read and transcribed (Muse Spark, SAM, Muse Voice Transcribe).
  • Baseten receives only claims built from public data, never citizen report data.
  • When you open the map, your browser loads map tiles from OpenFreeMap, imagery from NASA GIBS, and the MapLibre library from unpkg. Those services see your IP address, as with any website.

Browser storage

No cookies, ads, or analytics. The browser stores only your language choice, the side panel state, and the verifier token (verifiers only) in localStorage.

Retention and deletion

Reports are kept for the hackathon demo period and then deleted. A verifier can delete all citizen data of an incident at any time. To ask for deletion, open GitHub Issues and give the incident number only, without personal data.
